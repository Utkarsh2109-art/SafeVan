## ✨ Features

- 🔐 **Role-based Login** – Separate access for Parent, Driver & Admin
- 📞 **Phone & Email Login** – Flexible authentication options
- 🔍 **Google Sign-In** – One tap login with Google
- 🗺️ **Live Van Tracking** – Real-time location on Google Maps
- 💺 **Seat Booking** – Book seats for students easily
- 🔔 **Smart Notifications** – Pickup & drop alerts for parents
- 🛣️ **Route Management** – Optimized routes for drivers
- 💳 **Easy Payments** – Secure and cashless transactions
- 🌐 **Multi-language Support** – Change language option
